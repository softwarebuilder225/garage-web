# John's Garage

This is the car list. You can search, sort, add a car, and export a spreadsheet.

## Find a car

Use **Find a car** at the top of the page.

- **Search by name**: type part of the name, e.g. `toyota`
- **Made in**: USA, Europe, or Japan
- **Cylinders**: engine size
- **From year** / **To year**
- **Lowest MPG** / **Highest MPG**

The list updates as you type. If nothing matches, use **Clear filters**.

## Sort

Click a column heading to sort. Click the same heading again to reverse the order.

## Last search

The current search sits in the page address. Close the browser and open the same page again. It should look as you left it. You can bookmark it too.

## Export CSV

**Export CSV** saves the cars currently on screen (after any search or filters). Open the file in Excel or Google Sheets. Clear the filters first if you want every car.

## Add a car

Scroll to **Add a car**.

1. Enter the name, e.g. `Ford Pinto`.
2. Choose where it was made.
3. Fill in year, cylinders, engine size, weight, and 0–60 time.
4. MPG and horsepower can be left blank.
5. Click **Add car**.

The new car should show up in the list.

## If something goes wrong

- Click **Try again** if the list does not load.
- Empty required fields on the add form are marked in red.
- If the download fails, try it once more.

## Columns

| Column | Meaning |
| --- | --- |
| Name | Make and model |
| Year | Model year |
| Made in | USA, Europe, or Japan |
| MPG | Miles per gallon. A dash means unknown |
| Cylinders | Number of cylinders |
| Horsepower | Engine power. A dash means unknown |
| Weight (lbs) | Weight in pounds |
| 0–60 (sec) | Seconds from 0 to 60 mph |
